## 1. Resumen ejecutivo

Aware Gaming es un monorepo (Spring Boot 3.2 + React 18/Vite 5) de un equipo de No Country (2024). **Compila y arranca** con JDK 21 y Node 22/24, y ahora levanta completo en contenedores. Pero tiene **fallas graves de seguridad y de lógica de créditos** y **el login desde la UI está roto** desde el commit `a41ae8d` (las rutas pasaron a `/v1/api/*` y el front no se actualizó). La red de tests es mínima: un `contextLoads`. Cobertura de base del back: **34,5 % de líneas** y **0,1 % de ramas** (inflada por el seed y por Lombok). El front no tiene tests.
